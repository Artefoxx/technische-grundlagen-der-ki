# Technische Grundlagen der KI

Praktikumsversuche aus dem Modul **Technische Grundlagen der KI** im Studiengang Angewandte Informatik an der HTWG Konstanz.

Das Repository enthält Jupyter-Notebooks mit Messdaten, Auswertungen und Visualisierungen.

## Versuche

### Versuch 1 – Infrarot-Abstandssensor

Kalibrierung und Auswertung eines Infrarot-Abstandssensors.

- Auswertung und Visualisierung von Messdaten
- Modellierung der Sensorkennlinie mittels linearer Regression
- Berechnung von Abständen anhand der Kalibrierfunktion
- Flächenberechnung unter Berücksichtigung der Messunsicherheiten

**Technologien:** Python, NumPy, Matplotlib, OpenPyXL

*Durchgeführt zusammen mit Rostyslav Yefremov.*

### Versuch 2 – Bildverarbeitung

Analyse und Korrektur digitaler Bilder.

- Untersuchung von Bildern und Pixelintensitäten
- Dunkelbildkorrektur
- Hellbildkorrektur anhand von Referenzaufnahmen
- Erkennung und Analyse fehlerhafter Pixel

**Technologien:** Python, NumPy, OpenCV, Matplotlib

## Ausführung

Voraussetzungen: Python 3 und Jupyter Notebook.

Abhängigkeiten installieren:

```bash
pip install -r requirements.txt
```

Jupyter Notebook starten:

```bash
jupyter notebook
```

Die Notebooks befinden sich in den jeweiligen Versuchsordnern und können dort ausgeführt werden.
